# Mobile application examples

Independent Python-first Gramlot pages and their catalogue, owned by gramlot-capacitor.

See [the integration handoff](../../docs/110-mobile-gallery-contract.md) for the authoritative host/gallery contract. Add the parent `examples` directory to PYTHONPATH; mount `mobile_application.PAGES` with the module assets and the current Gramlot themes/collections. The module has no dependency on the gallery or a particular server adapter.

The local Kajenn configuration demonstrates mounting at `/device`. A host can choose a different prefix: page links and JavaScript imports are relative. `catalog.json` is the single page inventory. `page.py` shares Source declarations; pages and Logic use the existing `gramlot.device` Data contract. The native provider bundle is generated by `npm run device:build`.

The Mela appearance probe uses normal Gramlot controls and Data. Its “Preferenze” section is a UI demonstration, not persistent native preferences.

Do not include private APNs configuration, token stores or user media when distributing this module. The server-push registration callback must be configured by its host.
