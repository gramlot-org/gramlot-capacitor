## 015 · Local gallery environment

The dedicated recipe in `site/config.py` uses the existing `gramlot_py_server.gallery.stage` and Kajenn Application. Gallery code remains owned by gramlot-examples; no core or adapter runtime changes are included. Remote editing and filesystem IDE roots are not enabled.

The Compose overlay in `deploy/local-https/compose.gallery.yaml` extends the reusable Kajenn/Caddy environment. It reuses project `local-https`, its CA/data volumes and HTTPS port; the gallery image extends the locally built Kajenn image and refreshes unconstrained first-party releases. Start it with:

```sh
# Set this only when the Kajenn checkout is elsewhere.
export KAJENN_HTTPS_DIR=/path/to/kajenn/deploy/local-https
./scripts/start-gallery.sh
```

The default path matches the current sibling checkouts. The setup inherits the Kajenn environment's ignored `.env`; its current endpoint is `https://192.168.5.115:8443/gallery/`. The address is DHCP-assigned and must be reserved or updated if it changes. The official-gallery shell does not depend on this LAN endpoint.
